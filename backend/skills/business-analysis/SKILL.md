# DramaTalk 平台经营分析

## Overview

此技能用于生成 DramaTalk 平台的月度经营分析报告。通过执行 `query_business_data.py` 脚本查询 Doris 数仓，获取核心经营指标，然后进行专业的经营分析。

## 使用流程

### Step 1: 确认分析月份

向用户确认需要分析的月份，格式为 `YYYY-MM`（如 2026-04）。如果用户未指定，默认分析上个月。

### Step 2: 执行数据查询脚本

运行以下命令获取经营数据：

```bash
python ${CLAUDE_SKILL_DIR}/query_business_data.py --month 2026-04
```

将 `2026-04` 替换为实际需要分析的月份。

脚本会输出 JSON 格式的经营数据，包含以下指标：
- `recharge`: 充值数据（总额、笔数、ARPU、渠道分布）
- `new_users`: 新增用户数据
- `game`: 游戏数据（投注总额、结算总额、各游戏分布）
- `gift`: 送礼数据（送礼总额、收礼总额）
- `reel`: 短剧数据（解锁消费、观看用户数）
- `active_users`: 活跃用户数据（DAU、MAU）
- `revenue_summary`: 收入汇总（充值+订阅+广告）

如果需要指定数据库地址，可以加参数：
```bash
python ${CLAUDE_SKILL_DIR}/query_business_data.py --month 2026-04 --host 192.168.10.253
```

### Step 3: 分析数据并生成报告

基于查询结果，按以下结构输出经营分析报告：

## 输出格式要求

```markdown
# DramaTalk 平台经营分析报告 — {月份}

## 一、核心指标概览

| 指标 | 本月数值 | 环比变化 |
|------|----------|----------|
| 充值收入(USD) | $xxx | +xx% |
| 订阅收入(USD) | $xxx | +xx% |
| 新增用户 | xxx | +xx% |
| 月活跃用户(MAU) | xxx | +xx% |
| 游戏投注(beans) | xxx | +xx% |
| 送礼消耗(beans) | xxx | +xx% |

## 二、收入分析

### 2.1 充值收入
- 总充值金额、充值笔数、笔均金额
- Apple vs Google 渠道占比
- 一次性充值 vs 订阅充值结构
- 收入趋势判断（增长/持平/下降）及原因分析

### 2.2 订阅收入
- 新增订阅 vs 续订占比
- 订阅留存情况分析

## 三、用户分析

### 3.1 新增用户
- 本月新增用户总数
- 日均新增趋势
- 新用户质量（新用户充值转化率）

### 3.2 活跃度
- DAU/MAU 及比值（粘性指标）
- 活跃用户趋势

## 四、消费分析

### 4.1 游戏消费
- 总投注额、总结算额、平台净收入（投注-结算）
- 各游戏（TP/SP/CQ/GD）投注分布
- 游戏收入贡献排名

### 4.2 送礼消费
- 送礼总额（beans）
- 收礼总额（gems）
- 送礼活跃度

### 4.3 短剧消费
- 短剧解锁消费总额
- 解锁用户数
- 人均解锁消费

## 五、关键发现与建议

1. **亮点**：本月表现突出的指标及原因
2. **风险**：需要关注的下降趋势或异常
3. **建议**：基于数据的运营优化建议（2-3条）
```

## 分析原则

1. 所有结论必须基于数据，不做无依据的推测
2. 环比数据如果脚本未提供上月数据，标注"暂无环比"
3. 金额单位：充值用 USD，虚拟货币用 beans/gems
4. 数字使用千分位格式（如 1,234,567）
5. 百分比保留一位小数
6. 分析要有洞察，不是简单复述数字
